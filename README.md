# FlowCash

FlowCash — plateforme de paiement et de gestion financière en construction.

## Statut

Projet initialisé le 6 septembre 2026. Le socle Next.js/TypeScript est en place.

## Architecture

- Next.js + TypeScript
- Neon PostgreSQL
- Neon Auth
- Vercel

Supabase n'est pas utilisé dans l'architecture FlowCash.

## Développement

Les fonctionnalités métier, l'authentification, le moteur financier et les intégrations de paiement seront ajoutés progressivement après validation et tests de chaque couche.
